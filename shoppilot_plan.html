2. Product scope (what "production" means here)

  • Browser extension "ShopPilot" (Chrome Web Store + Firefox): registers the site's real APIs as structured agent tools on every supported store, in the user's own session. Human-in-the-loop checkout (spec-mandated confirm gate).
  • Platform adapters: Shopify first (one platform, ~60%+ storefronts with top-3 coverage), then WooCommerce, Magento. Platform-detection + per-adapter contract tests against real stores.
  • Merchant registry + dashboard (Model C SaaS): opt-in catalog registration in the agent tool registry, agent-analytics dashboard (visits, carts, orders, attribution).
  • Affiliate layer: attribution tags via aggregators (Cuelinks/EarnKaro) so revenue starts day 1.
  • Pro tier: unlimited stores, checkout automation, savings report ("saved you ₹1,240 this month").
  • Backbone: event instrumentation from day 1 (install → store-visit → tool-call → cart → checkout) — this dataset is the Pro/SaaS pitch.
